# 2026-11-24

- Demo bug fix (Single Attribute): dragging the target slider left the λ slider hidden under a loading spinner for a long time. Cause: the λ-direction handler added in a0b34b2 (by-ear down/up λ for pitch register) is wired to the target's `.change`, which fires on every drag tick; each event wrote to the λ slider with Gradio's default progress overlay, so one drag queued dozens of round-trips (slow over gradio.live). Fix in `demo/app.py`: both target `.change` handlers (σ note + λ direction) now use `show_progress="hidden"` and `trigger_mode="always_last"`. Checked that Gradio 6.28 accepts the options; not yet clicked through in the browser.
