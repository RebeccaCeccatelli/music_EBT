## Regressor accuracy: Anticipation duration label bug confirmed
- eval_final_regressors.py results (job 28699826, 1000 windows): REMI velocity/duration/pitch and Ant pitch, EBT + Llama: r 0.985–0.999. Ant duration (EBT 24934693, Llama 27933069): r 0.42 / 0.39.
- Cause: train_density_regressor.py samples non-note-only Anticipation windows at any offset; compute_duration_bias reads stride-3 from index 0, so 2 of 3 offsets give no duration fields → label 0.0. Training labels were 0 for ~2/3 of windows.
- Confirmed with triplet-aligned windows (ALIGN=1, job 28700069): r 0.939 (EBT) / 0.937 (Llama); true mean 0.027 (= corpus) but predictions 0.0094 / 0.0092 ≈ 1/3 of true. The regressors rank duration well but are scaled down ~3×; targets are on the true scale, so guidance direction is right but strength is mis-scaled (affects EBT and Llama PPLM alike). Not fixed (no new experiments); to state in thesis.
