## Survey: fix for the attention-check question that "won't play"
- Participants reported that in 1 of 25 questions either the reference or the second clip would not play.
- Cause: the `catch_change` attention check (1 per participant) uses the same audio hash for reference and test.
  `playCard` in `survey.js` tracked the current clip by hash, so clicking the second card of an identical pair paused/resumed
  the first card instead of switching (progress bar moved on the other card). Whichever card was played first worked.
- Fix: track by card (`current.card === card`) in `demo/showcase/site/survey/survey.js` and `it/survey.js`.
  Verified the Netlify deploy (zip built 2026-11-08) differs from the working tree only by this fix.
- Deploy: replace the two survey.js files in the Mac `listening-study/survey/` folder, then drag the folder onto Netlify → Deploys (same URL).
- Analysis note: responses to the catch_change trial collected before the fix may be affected; don't exclude participants on it alone.
