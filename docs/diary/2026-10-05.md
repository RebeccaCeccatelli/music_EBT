# 2026-10-05

## Decision: stop pretraining, wrap up the project
- Both active EBT runs (small-REMI s1, small-Ant-AT stab+) had crashed on
  2026-10-01 with "Disk quota exceeded" — scratch at 1024/1024 GB. Root
  cause: every daily auto-resume creates a new checkpoint dir with its own
  top-10, so 219 dirs / 1,117 ckpts / ~972 GB had piled up.
- Decided **not** to relaunch. The attribute regressors are pinned to a
  specific EBT checkpoint's embedding space, so further pretraining would
  force retraining every regressor and re-running every sweep anyway; and
  stab+ had plateaued (val ~1.022 flat from 43.1k to 44.8k). Final
  checkpoints are listed in [STATUS.md](../STATUS.md).
- Committed the `save_top_k_ckpts` 10 → 3 (and `min_lr_scale` 10 → 3)
  default change in `train_model.py` (378dfc3).

## Regressor retraining against the final checkpoints
- The fixed Anticipation pitch_register retrain from 2026-09-24 (job
  23658023) never produced a regressor: **TIMEOUT** after 4/10 epochs, and
  every epoch logged `train_loss=nan`.
- Likely NaN cause (not yet confirmed — a CPU check on the login node was
  too slow to finish): since the windowing fix, `DensityDataset` runs
  `_anticipation_triplets()` first; a sequence with no real events left
  gives empty hard/future windows → `e_mean = 0/0 = NaN`, and one such
  sample makes the whole batch loss NaN.
- Fix in `attribute_control/train_density_regressor.py`: resample when a
  sequence has < 1 triplet of usable tokens; raise if the checkpoint's
  embedding contains NaN/Inf; raise on the first non-finite train loss
  with a breakdown (bad e_mean rows / labels / preds), so a broken run
  dies in minutes instead of burning 4 GPU-hours.
- Also found: `train_density.sh` auto-selects the EBT ckpt with the
  lowest valid_loss in its filename — the same artifact trap (that's how
  the Ant regressors got paired with step 55,500 / 0.3335). Passed
  `CHECKPOINT=` explicitly for every job.
- Submitted (REMI → `ebt-symb-small-remi-s1` step 33,732, val 0.7150;
  Ant → `ebt-symb-small-ant-at-full-s1` step 88,800, val 0.9903):
  - REMI density 24934689, velocity 24934690, duration 24934691,
    pitch_register 24934692 (defaults, ~3–12 min each previously)
  - Ant duration 24934693, Ant pitch_register 24934694 (`NOTE_ONLY_WINDOW=1`)
    — `EPOCHS=5 MAX_TRAIN_SAMPLES=300000 --time=06:00:00` since the old
    run managed ~1 epoch/hour at 500k samples.
